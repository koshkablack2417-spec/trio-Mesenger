# Трио: мессенджер для звонков

Мессенджер в духе Telegram и WhatsApp: чаты, группы, каналы, видеокружки, звонки и видеозвонки.
Стек: **Expo (React Native) + TypeScript**, бэкенд **Supabase**.

## Что уже есть

- Вход по номеру телефона (SMS-код) и по e-mail (код на почту) через Supabase Auth
- Экран «Защити аккаунт»: вошёл по e-mail → обязан добавить телефон (без «Пропустить»); вошёл по телефону → может добавить e-mail или пропустить
- Фото, видео (до 50 МБ), видеокружки (запись до 60 секунд) и контакты в чате, кнопка «+» рядом с полем сообщения
- iPad и веб: экран входа по QR-коду (пока заглушка)
- Личные чаты, группы (до 300 участников, включая владельца) и каналы, сообщения в реальном времени
- Добавление участников группы по номеру телефона при создании
- В каналах писать могут только владелец и админы (правило в базе)
- SQL-схема с защитой строк (RLS), миграции в `supabase/migrations/` (уже применены к проекту `trio`)

## Запуск

```bash
cp .env.example .env
npm install
npx expo install --fix   # подберёт совместимые версии пакетов
npx expo start
```

Если после обновления зависимостей что-то не запускается, выполни `npx expo install expo-image-picker expo-contacts expo-video`.

Открой в Expo Go на телефоне или нажми `w` для веб-версии.

## Настройка отправки кодов (Supabase Dashboard)

Код отправляет сам Supabase, в приложении для этого ничего писать не нужно. Нужны настройки в панели:

**E-mail**
1. Authentication → Email Templates → **Magic Link** (и **Confirm signup**): добавь в текст `{{ .Token }}`,
   например «Твой код для входа в Трио: {{ .Token }}». Без этого придёт ссылка, а не код.
2. Встроенная почта Supabase шлёт мало писем в час. Для реальной работы подключи свой SMTP:
   Authentication → Emails → SMTP Settings. Сейчас используется Brevo: хост `smtp-relay.brevo.com`, порт `587`,
   логин и SMTP-ключ берутся в панели Brevo (SMTP & API → SMTP). Адрес отправителя должен быть подтверждён в Brevo.

3. Шаблон **Change Email Address** (Authentication → Emails → Templates) тоже должен содержать `{{ .Token }}`: он нужен, когда телефонный пользователь добавляет e-mail.

**Телефон**
1. Authentication → Providers → **Phone**: включить и выбрать провайдера (Twilio, Vonage или MessageBird).
2. Для проверки без SMS можно добавить тестовые номера с фиксированным кодом в тех же настройках.

## Сборка файла для установки (EAS Build)

Нужен бесплатный аккаунт на expo.dev. Один раз: `npm i -g eas-cli`, `eas login`, `eas init`.

- **Android (.apk):** `eas build -p android --profile preview`. Через несколько минут EAS даст ссылку на скачивание APK.
- **iPhone:** нужен платный Apple Developer ($99 в год). `eas build -p ios --profile production`, затем `eas submit -p ios` отправит сборку в TestFlight. Без этого аккаунта установить своё приложение на iPhone нельзя, пока можно пользоваться Expo Go.
